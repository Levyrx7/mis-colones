# Mis Colones

App personal de finanzas en colones: pagos por quincena, gastos con íconos, metas de ahorro y reportes mes a mes.

- Funciona en el iPhone desde Safari: **Compartir → Agregar a pantalla de inicio**.
- Los datos se guardan solo en el teléfono. Usa **Mi plan → Respaldo** para descargar y cargar respaldos.
- Este repositorio no contiene datos personales.
